Repose Audio is a cross-platform audio player built as a reference example for the Repose GUI framework.

Features:
• Audio decoding via Symphonia (MP3, FLAC, OGG, WAV, AAC, and more)
• Low-latency playback via CPAL
• Embedded metadata and album art display
• Playlist management with track reordering
• Cross-platform: Linux, macOS, Windows, Web (WASM), Android
• Native file open dialogs
• Open source (LGPL-2.1)
